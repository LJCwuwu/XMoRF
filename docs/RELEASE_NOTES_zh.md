- 两个补充包共 417 个文件的大小和 SHA256 全部通过。

- 固定最终配方：S0 嵌套模型、独立核心 FT40G、独立区域 R65_G，各 24 个权重。

## GitHub 中放什么

仓库放本候选目录中的源码、配置、文档和小型示例。`weights/`、`data/`、完整特征缓存和训练输出已经在 `.gitignore` 中排除。

模型权重应单独作为 Release 附件或存放在提供持久标识的数据仓库。现有服务器可用
`scripts/prepare_weights.py` 生成正确的最终权重目录，不需要再上传整个实验项目。

原始基准数据保留原作者来源与使用条款。当前候选包含精确文件清单和从原项目准备数据的脚本；公开数据包的方式需在发布前按原始来源的许可确定。
